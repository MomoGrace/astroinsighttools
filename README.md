Brand: Astro Insight Tools  
Domain: AstroInsightTools.com

## What is included
- 20 real browser-based tool pages in `/tools/`
- 30 SEO/GEO article pages in `/articles/`
- Advanced responsive UI in `/assets/style.css`
- Tool logic in `/assets/tools.js`
- Homepage, tools index, articles index
- About, Contact, Privacy Policy, Terms, Disclaimer
- `sitemap.xml`, `robots.txt`, `ads.txt`
- AdSense auto ads script using publisher ID `ca-pub-5952834143682557`

## Deployment
1. Upload all files to a GitHub repository.
2. Connect the repository to Vercel.
3. Set the custom domain to `astroinsighttools.com` and `www.astroinsighttools.com`.
4. Make sure `ads.txt` is accessible at `https://astroinsighttools.com/ads.txt`.
5. Submit `https://astroinsighttools.com/sitemap.xml` in Google Search Console.
